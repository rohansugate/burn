What it is

You can run a browser demo here — upload a clip and it transcribes, translates, and burns captions in your tab. Nothing is uploaded to a server. For page URLs, long videos, and higher-quality Whisper, clone the repo and run it locally.

Run it

git clone https://github.com/rohansugate/burn.git
cd burn
chmod +x start.sh
./start.sh

Needs Python 3.11+, FFmpeg with libass, and Playwright Chromium. Full setup is in the README.
